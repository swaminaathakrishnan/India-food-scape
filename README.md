# India-food-scape

A project exploring the culinary landscape of India — mapping, documenting, and analysing regional food cultures, ingredients, dishes, and traditions across the subcontinent.

## Overview

India-food-scape aims to capture the diversity and richness of Indian cuisine across its many regions, languages, and communities. Whether you're interested in street food, home cooking, festival dishes, or ingredient origins, this project serves as a resource and starting point.

## Features

- Regional food mapping and categorisation
- Dish and ingredient documentation
- Cultural and historical context
- Data-driven insights into food trends and patterns
